# Calculate precision matrix for a subset of nodes

Internal function to find the precision matrix of a subset of values
(specified via indices) using block-inversion block-inversion of sparse
matrices to find the inverse of the submatrix for the selected indices.
Note that, even when given a sparse matrix, the precision matrix for a
subset of nodes will be in general dense.

## Usage

``` r
calc_subprec(mat, indices)
```

## Arguments

- mat:

  n x n positive semidefinite precision matrix, generated by the Matrix
  package

- indices:

  numeric indices for the rows/columns of the submatrix to be generated.
  All indices must be between 1 and n with no repeated indices
