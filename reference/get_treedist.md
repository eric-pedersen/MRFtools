# Path length distance between two nodes of a phylogenetic tree

Internal function to get the shortest phylogenetic distance between two
nodes in a given tree

## Usage

``` r
get_treedist(tree, tip1, tip2)
```

## Arguments

- tree:

  a phylo4 tree object

- tip1:

  The starting tip (either named or as an index)

- tip2:

  the ending tip for the path
